# Security

## Reporting a problem

Use GitHub's private vulnerability reporting: the repository's **Security** tab, **Report a
vulnerability** (the owner turns it on under Settings > Code security). Please don't open a public
issue for a vulnerability. Ordinary bugs go on the
[issues page](https://github.com/addohm/leprofit/issues).

## Secrets

None: the addons and the tools use no secrets, and the addons send nothing to other players or
anywhere else (no addon messages). Never commit secrets all the same.

## Access

The repository is public (GNU GPLv3); only the owner and this workspace's deploy key can push.

The code lives at `addohm/leprofit` on GitHub, owned by addohm; this
workspace pushes to it with a deploy key.
